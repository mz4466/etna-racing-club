📖 GUIDA — CREA CAMPIONATO
1. Informazioni Campionato

Inizia compilando i campi nella sezione in alto:

  • Nome Campionato — Il nome ufficiale, es. "Traiettorie Gelate". Verrà usato come titolo nella pagina generata.
  • Anno — L'anno della stagione, es. 2026.
  • Categoria — Scegli tra Campionato, Trofeo o Open.
  • Classe Auto — Le auto ammesse, es. "GR.3 — Solo".
  • Stagione / Suffix — Un suffisso opzionale per distinguere campionati dello stesso anno, es. "q1" o "autunno". Serve anche per generare il nome del file.
  • Descrizione — Testo opzionale che appare come sottotitolo nella pagina pubblica.
2. Nome File Generato

Nella barra laterale sinistra trovi il nome del file che verrà creato nel repository GitHub. Viene generato automaticamente dal nome, anno, categoria e suffix che inserisci. Esempio: traiettorie-gelate-2026-campionato-q1.html

3. Aggiungere i Round

Clicca il pulsante "＋ Aggiungi Round" per inserire una gara nel calendario. Per ogni round puoi configurare:

  • Round # — Numero progressivo della gara.
  • Circuito — Nome della pista, es. Autopolis.
  • Data Gara — La data programmata.
  • Giri — Numero di giri della gara.
  • Meteo — Condizioni atmosferiche previste.
  • Consumo Gomme / Carburante — Moltiplicatori di usura.
  • Gomme Disponibili — Mescole ammesse, es. Soft / Medium / Hard.
  • Note — Informazioni aggiuntive, es. "Pit stop obbligatorio".
  • Link Risultati — Una volta pubblicati i risultati, inserisci qui il nome del file HTML, es. risultati-01.html. Il pulsante nella pagina pubblica si attiverà automaticamente.
4. Gestire i Round
  • Clicca sull'intestazione di un round per espanderlo o comprimerlo.
  • Puoi aggiungere quanti round vuoi senza limiti.
  • Clicca "✕ Rimuovi Round" in fondo al round per eliminarlo.
  • Il riepilogo nella barra laterale mostra tutti i round aggiunti in tempo reale.
5. Anteprima

Clicca "👁 Anteprima" per vedere come apparirà la pagina pubblica prima di pubblicarla. L'anteprima si aggiorna ogni volta che la apri.

6. Pubblicare su GitHub
  1. Inserisci il tuo Personal Access Token (PAT) GitHub nella barra laterale. Il token deve avere i permessi Contents: Read & Write sul repository.
  2. Clicca "Verifica Connessione" — il pallino verde conferma che la connessione funziona.
  3. Clicca "⬆ Pubblica su GitHub". Il file verrà creato (o aggiornato se esiste già) direttamente nel repository mz4466/etna-racing-club.
7. Scaricare HTML

Se preferisci, clicca "⬇ Scarica HTML" per scaricare il file in locale e caricarlo manualmente su GitHub.

💡 Suggerimento: Puoi tornare su questa pagina in qualsiasi momento per aggiornare il campionato — basta ripubblicare. GitHub sovrascriverà automaticamente il file esistente.
